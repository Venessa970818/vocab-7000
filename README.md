# 7000單字 - 無印風

一個無須安裝套件、不連資料庫、且具備分級與本地進度儲存的極簡風 7000 單字翻轉字卡網頁。

## 功能清單
- **選擇難度**：讓使用者點選 Level 1 到 Level 6 來載入對應等級的單字。
- **翻轉字卡**：點擊單字卡顯示中文翻譯與詞性，並提供「記得」與「不熟」按鈕。
- **進度記憶**：利用瀏覽器 localStorage 自動儲存進度；將不熟的單字集中到「不熟單字區」，方便針對弱點加強複習。

## 驗收方式
1. 開啟 `index.html`，確認畫面能從雲端載入單字，並看到 Level 1 到 Level 6 的按鈕。
2. 點擊「學習新字」進入卡片測驗，點擊字卡能翻面顯示中文。
3. 點選「不熟」後，該單字會出現在主畫面該 Level 下方的「不熟單字區」。
4. 重新整理網頁，確認剛才選擇的進度有被保留，並反映在主畫面的進度條上。

## 怎麼使用
由於這是一個完全靜態的 HTML 檔案，無需設定後端或安裝任何套件。
1. 下載專案。
2. 直接在任何現代瀏覽器（如 Chrome, Safari, Edge）中打開 `index.html`。
3. 選擇您想挑戰的等級，開始背單字！
